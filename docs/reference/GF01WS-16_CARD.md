## Назначение

`GF01WS-16` — рабочая станция сектора Good Fox. Используется для администрирования и работы с `Cr01MS-32`:

- подключение к Cr01 по SSH;
- работа с Grafana;
- разработка и обслуживание среды AID.

Пользователь/владелец отдельно не уточнён.
