# FBl-2core

Текущая версия: **0.9.1B**.

Единый NixOS flake Fox Byte Lab для `Cr01MS-32` и `GF01WS-16` 

Cr01MS-32 - стационарный пк
GF01WS-16 - ноутбук

## Основной подход
 Главный принцип - общая стандартизация портов и оснвополагающих механизмов кеширования и работы программ. 
 Registry папка отвечает за возможность вносить в реестр основополагающие данные для единого согласования кеширования, портов и загрузке системы, а так же работы внутри home lab сети.
 Таким образом мы всегда знаем какими портами пользуются конкретные службы, какими зеркалами руководствуется система при сборке и как себя ведет система в сети.
