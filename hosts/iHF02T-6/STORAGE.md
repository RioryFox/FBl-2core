# iHF02T-6 — накопители

Обновлено: 2026-08-23

## Установлено

### Western Digital Caviar Black 1 TB

- Модель: `WD1001FALS-40U9B0`
- Серийный номер устройства: `WD-WMATV5102851`
- Форм-фактор: 3.5″
- Интерфейс: SATA
- Скорость вращения: 7200 rpm
- Кэш: 32 MB
- Дата производства: 2009-12-30
- Текущая роль: внутренний системный HDD iHF02T-6; точная разметка требует проверки
- План: после переноса системы iHF на SSD 256 GB установить WD1001FALS во внешний бокс для 3.5″ SATA с отдельным питанием и использовать как `IHF02_MIRROR`
- Будущая роль: внешнее файловое зеркало iHF02T-6 вместо текущего mirror-накопителя
- Текущее устройство: `/dev/sdb` на момент инвентаризации 2026-08-22; не использовать имя устройства как постоянный идентификатор
- Статус: подключение подтверждено через SATA; полный SMART-тест ещё требуется
- Фото: https://drive.google.com/file/d/1RYzB-E8l4qnqni4L7DUWwKfOx34xgNeQ/view

## Запланировано

### SSD 256 GB из Cr01MS-32

- Текущая роль: системный SATA SSD Cr01MS-32
- План: после установки нового SSD 1 TB в Cr01 перенести этот SSD внутрь iHF02T-6 вместо WD1001FALS
- Будущая роль: внутренний системный SSD iHF02T-6 для NixOS и сервисов HF
- Монтаж: может потребоваться переходная рамка 2.5″ → 3.5″ и проверка поведения температурного датчика iMac
- Статус: запланировано, ещё не перенесён

### Текущий mirror-накопитель iHF02T-6

- Модель: `TOSHIBA DT01ACA100`
- Серийный номер: `663XY74NS`
- Объём: 1 TB
- Подключение: USB
- Текущее устройство: `/dev/sda` на момент инвентаризации 2026-08-22; имя может измениться после перезагрузки
- Текущая роль: внешнее зеркало iHF02T-6
- План: заменить на WD1001FALS 1 TB во внешнем боксе
- Дальнейшая роль: определить после инвентаризации модели, серийного номера и SMART
- Важно: WD1001FALS нельзя подключать через обычный пассивный бокс для 2.5″ SSD; 3.5″ HDD требует отдельного 12 V питания

## Проверка WD1001FALS

```bash
lsblk -o NAME,SIZE,MODEL,SERIAL,TRAN,FSTYPE,LABEL,UUID,MOUNTPOINTS
sudo smartctl -x /dev/sdX
sudo smartctl -t long /dev/sdX
```

После завершения long-теста повторить `sudo smartctl -x /dev/sdX` и обновить этот реестр.
